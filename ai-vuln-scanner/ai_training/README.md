# AI Training Workspace

이 폴더는 팀원이 AI 기반 취약점 탐지 기능을 추가하기 위한 작업 공간입니다.

## 권장 작업 흐름

1. `data/raw/`에 원본 데이터셋을 둡니다.
2. 전처리 결과는 `data/processed/`에 둡니다.
3. 학습된 모델 파일은 `models/`에 둡니다.
4. 실험 로그와 결과는 `runs/`에 둡니다.
5. 앱에 연결할 안정화된 추론 코드는 `scanner/` 패키지에 추가합니다.

## Git에 올리지 않는 것

아래 파일들은 용량이 크거나 민감할 수 있으므로 Git에 올리지 않습니다.

- 원본 데이터셋
- 전처리된 대량 데이터
- 학습된 모델 파일
- 실험 로그와 체크포인트

필요하면 작은 샘플 데이터만 별도로 만들어 `samples/`에 추가하세요.

## 앱 연동 방향

현재 앱은 `scanner.rules.analyze_code()`의 규칙 기반 결과를 사용합니다.
AI 모델을 붙일 때는 아래처럼 분리하는 것을 권장합니다.

```text
scanner/rules.py       규칙 기반 분석
scanner/ai_model.py    AI 모델 로딩 및 추론
scanner/analyzer.py    규칙 결과와 AI 결과를 합치는 통합 분석기
```

처음에는 규칙 기반 결과를 유지한 채 AI 결과를 추가 필드로 붙이는 방식이 안전합니다.
